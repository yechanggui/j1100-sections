规范与断面的对应
SAE J182车辆三维参考系与基准标记。本站所有坐标与截面都换算到 J182：X 向后为正、Y 向左为正、Z 向上为正。CCSA 原模型 X 向前为正，已翻转 X。
SAE J1100机动车尺寸。除地面相关尺寸外，均在 J182 参考系下量取。H30、L53、H61、W3、W31 等布置尺寸给出乘员舱内部包络。包络 → 顶盖、侧围、门槛、车门断面的边界。
白车身断面顶盖边梁、A/B 柱、门槛、地板、前围的钣金截面：腔体尺寸、焊接翻边、搭接关系。在 J1100 包络之外、外观面之内设计。
内外饰 / 密封条断面门内饰、柱饰板、仪表板；门框、玻璃导槽、门槛密封条的安装空间与压缩量。间隙面差（GF）是外观质量项。本模型含门内饰、柱饰板、仪表板；不含顶棚、地毯、密封条。
DTS尺寸技术规范：每一项 = 唯一键 + 截面 + 测量方法 + 目标/公差 + 约束的断面图层。本站的目标值是示例。见 data/dts_catalog.json，可直接替换。
